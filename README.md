## Como publicar na Hostinger

1. hPanel → Sites → Gerenciador de Arquivos.
2. Abra `public_html` e apague o `default.php`, se existir.
3. Envie o `index.html` (e a pasta `fotos`, se houver).

## Fotos do mural

Coloque `foto1.jpg` até `foto9.jpg` numa pasta `fotos/` ao lado do `index.html` para substituir os quadrados coloridos do topo.

## Trocar o WhatsApp
